# ATC4

Рабочий проект ATC4: инструменты и интерфейс ATC4-RU, а также отдельный прототип ATC Next на Rust и wgpu.

Репозиторий: https://github.com/bulinmaks-hash/ATC4

## Начальное состояние

Первый коммит содержит README и настройки Git. Существующие локальные исходники, ресурсы и результаты работы сохраняются в рабочей папке; они не включены в начальный коммит. Перенос исходников выполняется отдельно с учётом текущих владельцев файлов и проверок.

## Структура локального рабочего каталога

- `tools/` — инструменты подготовки данных, проверки и координации.
- `ui/` — интерфейсы и средства доставки ATC4-RU.
- `prototypes/atc-next/` — прототип Rust/wgpu и независимые библиотеки.
- `coordination/` — учёт версий рабочего каталога.
- `analysis/` — отчёты, проверки и сведения о происхождении данных.

ATC4-RU и ATC Next — отдельные приложения. Наличие графического прототипа не означает готовность полного игрового цикла.

## Разработка

Перед изменениями прочитайте локальный `AGENTS.md`. Для ATC Next сначала изучите `prototypes/atc-next/orchestration/plan.json` и `contracts.json`, затем выполните из корня:

```powershell
python tools/atc_next_orchestrator.py status
```

Задачи движка требуют закрепления владельца и непересекающихся путей записи. Общие сборки, GPU-проверки и публикации согласуются через существующий план.

Инструкции по сборке и ограничения прототипа находятся в локальном `prototypes/atc-next/README_RU.md`. Оригинальные ресурсы ATC4 и наборы самолётов необходимы отдельно: клонирование этого начального репозитория не устанавливает игру. Локальные инструментарии, ресурсы, сборки и кэши исключены через `.gitignore`.
